# XZM Custom - Web Store

Tienda web oficial para el bot **XZM**, diseñada para la personalización de perfiles mediante el canje de XP y Niveles.

## 🚀 Características
- **Sincronización en Tiempo Real:** Conecta con el bot mediante una API local para obtener estadísticas de usuario.
- **Tienda Modular:** Interfaz para comprar contornos, fondos y estilos.
- **Diseño Moderno:** Interfaz tipo "Glassmorphism" optimizada para móviles y escritorio.

## 🛠️ Tecnologías
- HTML5 / CSS3 (Custom Properties & Grid)
- JavaScript (ES6 Modules)
- Conexión vía Fetch API a la Web API del Bot.
